Jellyfin-web item details

These patches run in the web client. They need File Transformation or JavaScript Injector, and the inject toggle below must stay on. Native apps are not patched.

Install the TMDB Search script into jellyfin-web index.html. Turn this off to remove every web-client patch below.
Fetch /TmdbSearch/Items/{id}/Metadata and paint poster, overview, and other TMDB fields before Gelato GetItem finishes. Other details-page toggles require this.
Keep the original GetItem request running so Gelato/AIOStreams can fill the version panel after metadata is shown. Turn off for a metadata-only preview with no playback for unowned titles.
Suppress jellyfin-web Loading.show and the full-page blue spinner once TMDB metadata is on screen. Stream timeouts still belong to AIOStreams/Gelato.
Un-hide the Play button as soon as metadata appears. It stays disabled until a real stream exists — never Path=/stub. jellyfin-web otherwise hides Play when MediaSources are empty.
If GetItem errors, returns empty sources, or only /stub placeholders, replace the version-panel spinner with "No streams available".
Return TMDB series/season metadata immediately so ChildCount and overview are not replaced by a hanging or thin GetItem. Turn off to wait for GetItem on those pages.

Series children

Answer /Shows/{id}/Seasons and series GetItems?ParentId= with TMDB seasons so unowned shows list seasons without waiting on Gelato insert.
Answer /Shows/{id}/Episodes and season GetItems?ParentId= with TMDB episodes for unowned seasons.
Return an empty /Shows/NextUp?SeriesId= list for TMDB stubs so jellyfin-web does not fall through to global continue-watching titles.

Fallbacks for unowned titles

If GetItem still 404s after Gelato insert, serve the cached TMDB search stub so the details page is not blank. GetItem is never skipped on the way in.
Turn ThemeMedia, Similar, Ancestors, and SpecialFeatures 404s for TMDB stubs into empty 200 responses so accessory widgets do not hang.
Fetch TMDB CDN artwork for search stubs so posters still load after a Gelato cache wipe.
